# ShopSphere 🛍️

A responsive e-commerce product catalog built as part of the Thiranex Web Development Task 5.

## Features

- Responsive frontend
- Modular JavaScript architecture
- Client-side routing
- Product catalog
- Product details
- Shopping cart
- Lazy-loaded images
- Responsive design

## Technologies

- HTML5
- CSS3
- JavaScript

## Deployment

Deployed using Vercel.
